# 事件模式平台

三个协作模块,支撑带模式演进的事件流:

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 模式注册 | `schema_platform/registry.py` | 稳定数字字段 ID、版本化模式;发布/回退原子切换可见版本,发布前校验全部活跃消费者契约 |
| 事件接入 | `schema_platform/ingestion.py` | 按事件声明的原版本验证并规范化;无效事件隔离;有效事件与全部投影原子落库 |
| 消费者投影 | `schema_platform/projection.py` | 消费者固定"字段 ID → 类型"契约;按契约为每个事件生成投影 |

`schema_platform/__init__.py` 中的 `EventPlatform` 是组合根,负责接线,
并在消费者注册/升级时对照当前可见模式做 fail-fast 校验。

## 核心不变式

- **字段身份 = 数字 ID**:显示名称可跨版本重命名,不影响字段身份与投影键。
- **发布/回退原子性**:先校验(活跃消费者的固定字段必须仍在且类型兼容),
  通过后才切换可见版本;失败时状态完全不变。
- **过渡期**:发布后旧版本保持 `PUBLISHED`,新旧生产者都能提交有效事件,
  直到管理员 `retire` 结束过渡期。
- **接入原子性**:先按原版本验证 → 再算全部投影 → 最后一次性落库;
  无效事件进隔离区,绝不留下部分投影。
- **投影补全**:旧版本事件缺少消费者所需字段时,用最新已发布版本的默认值补全。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

`tests/test_schema_platform.py` 交错执行发布、旧版写入、消费者升级与
失败回退,逐步核对各方看到的版本与数据;另含并发写入 + 并发发布的
投影完整性测试。
